# IPTransit-FR Website — Version 4

A professional redesign of the IPTransit-FR online bookstore inspired by established bookstore e-commerce patterns while maintaining an original visual identity.

## Version 4 improvements

- Large, prominent global search
- Utility bar and category navigation
- Professional hero photography
- Promotional / trust strip
- Best Sellers section
- New Releases section
- Category tiles
- Editorial discovery blocks
- Reading Journal / content cards
- More refined product cards
- Functional browser cart and wishlist
- Shop filtering and sorting
- Individual book details
- About, Contact, FAQ, Privacy, and Terms pages
- Optimized WebP imagery
- GitHub Pages-friendly relative paths
- `.nojekyll` included

## Upload to GitHub

Upload the **contents** of this ZIP directly to the root of the repository:

```text
assets/
pages/
index.html
404.html
README.md
CREDITS.md
.nojekyll
.gitignore
VERSION
```

Then enable GitHub Pages from the `main` branch and `/ (root)`.

## Important

Version 4 is still a front-end demo. Live payment processing, customer accounts, inventory, shipping APIs, database storage, and transactional email are not connected.
